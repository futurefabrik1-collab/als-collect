ALS Collect for Windows — EXPERIMENTAL, UNTESTED BUILD

This build is made automatically on GitHub's Windows machines. Nobody has run it
on a real Windows PC yet. The macOS version is the tested one.

Run it: unzip the folder anywhere, open it, double-click "ALS Collect.exe".
Windows SmartScreen will warn that the app is unrecognised (it is not signed):
click "More info", then "Run anyway".

Needs the Microsoft Edge WebView2 runtime (built into Windows 10/11).
MIDI clips play through the "Microsoft GS Wavetable Synth" as a rough
approximation of the Set's sound.

Problems? Open an issue at https://github.com/futurefabrik1-collab/als-collect/issues
with what you did, what happened, and your Windows + Live versions.
